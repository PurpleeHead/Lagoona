# Lagoona

Одностраничный сайт гостиничного комплекса, выполненный в рамках практики HTML/CSS-вёрстки.

Проект создан для отработки семантической разметки, позиционирования элементов, работы с блоками и построения сложной структуры страницы.

## 🌐 Demo

[Посмотреть проект](https://purpleehead.github.io/Lagoona/)

## 🛠 Технологии

* HTML5
* CSS3
* Flexbox
* БЭМ
* Git / GitHub

## ✨ Реализовано

* Семантическая HTML-разметка
* Структурированная вёрстка страницы
* Работа с Flexbox
* Сложное позиционирование элементов
* Карточки и информационные блоки
* Формы и элементы интерфейса
* Работа с изображениями
* Организация CSS по компонентному принципу

## 📄 Тип проекта

**Одностраничный статичный сайт.**

Проект не является адаптивным и ориентирован на демонстрацию навыков классической HTML/CSS-вёрстки.

## 🎯 Цель проекта

Практика создания сложных интерфейсных страниц и закрепление навыков:

* HTML5;
* CSS3;
* семантической вёрстки;
* Flexbox;
* БЭМ;
* позиционирования элементов;
* структурирования CSS-кода.
